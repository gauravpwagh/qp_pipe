3. Or: auto-detect & stitch the whole image

Best-effort: each detected line is read as plain text unless it looks like a formula (has "=" and a lot of math/digit characters), in which case it's converted via LaTeX-OCR instead - then everything is stitched back together in order. Works well for a formula written on one line (e.g. "UR = 50-45/50 x 100 = 10%"); a stacked fraction spanning two visual rows will get split into separate text lines instead - use the crop tool above for those. Always check the line list below and fix anything misclassified before copying.
